# NFL Pool — Sports API Integration

A personal React project developed to track NFL team performance throughout the regular season for a friendly pool among friends.

The application integrates with the MySportsFeeds API to retrieve sports data and uses React to present the information.

## Tech Stack

- React
- JavaScript
- SASS
- BEM CSS methodology
- MySportsFeeds API

## Live Application

[Visit Plague Pool](https://plaguepool.com/)

The live website runs a newer, actively maintained version of the application with significant component enhancements and improvements.

## Project Background

This repository contains an earlier public version of the application.

Development has continued in a separate private repository, where the application has evolved considerably beyond the implementation available here.

The public repository is retained to demonstrate the project's earlier React implementation and sports API integration.

## Notes

The application depends on an external sports data API. Running it locally may require API credentials and additional configuration.

API credentials are not provided in this repository.
